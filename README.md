# Tempogatchi Pet
A temp/humidity sensing classroom pet for Herbert J. Russell West End Academy. We developed this prototype as the final project for our Spring 2026 Arduino Prototyping Class (LMC 4813).

## Project Team

- Ari Hammond: Graphics Artist, Code for LCD Screen, Early Sketches
- Victor Samuel: Microphone Code, Documentation Lead, Liason to the School
- Sonakshi Sisodiya: Igloo enclosure, Neopixel Code, Lead Videographer
- Deepthi Munagapati: Web Developer for Data Visualization Dashboard

## Project Goals

- **Data Activation:** Create an engaging and physical activation from environmental data
- **Demonstrate Mastery:** Apply and extend course concepts in physical prototyping and environmental sensing
- **Community Co-Design:** Prototype for a public school context

# Project Documentation

## Materials

### Electronic Components
- Arduino UNO R4
- DHT11 Temperature Sensor
- Power Supply Module + 9V Battery
- Waveshare 2in LCD Module
- 16-bit NeoPixel Ring

### Software/Other Technology
- Arduino IDE
- Digital Drawing Software (we used Procreate)

### Physical Materials
- Large Cotton Balls
- Modeling Clay
- Coils of Wire
- Cardboard for base
